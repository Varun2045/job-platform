# Support Guidelines

Thank you for using the Job Monitor Platform! Here is how you can get help:

## 1. Documentation
Please check the following resources first:
- [README.md](./README.md) - Project overview and installation steps.
- [Architecture Guide](./docs/Architecture.md) - Detailed diagrams and system flow.
- [API Documentation](./docs/API.md) - REST endpoints guide.
- [Troubleshooting Runbook](./docs/Troubleshooting.md) - Solutions to common errors.

## 2. GitHub Discussions & Issues
- **Questions & Discussions**: For setup questions, configuration tips, or feature ideas, please use the Discussions tab on GitHub.
- **Reporting Bugs**: If you find a verified bug, please open a GitHub Issue. Be sure to include your Node.js version, configuration variables, and error logs.

## 3. Commercial Support
For custom scraping plugins, enterprise integrations, or hosting support, please contact the maintainers at `support@jobmonitor.org`.
