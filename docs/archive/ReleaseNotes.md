# Release Notes History (Archived)

Version history details for Job Monitor Platform from initial launch to public release.

---

## Version 4.1.0 (Public Release candidate)
*Release Date: 2026-07-08*
- **Features**: Complete production validation test suites including Playwright browser E2E tests, REST integration, failure injection, and scale performance run suites.
- **Fixes**: Error insulation in the email alerts queue, CORS flexibility for localhost loopback dynamic ports.

## Version 4.0.0 (Autonomous Copilot)
*Release Date: 2026-06-15*
- **Features**: Integrated autonomous CareerAgent, interactive Skill Gap Engine with dynamic study syllabus generators, and Playwright enrichment.

## Version 3.0.0 (Express Server & Database)
*Release Date: 2026-04-10*
- **Features**: Added REST API Server, dashboard endpoints, authentication middleware, and Supabase cloud database adapter.

## Version 2.0.0 (Local Engine)
*Release Date: 2026-02-18*
- **Features**: Core Cheerio HTML scraper fallback and TF-IDF Cosine Similarity resume matching logic.

## Version 1.0.0 (Initial MVP)
*Release Date: 2026-01-05*
- **Features**: Initial command-line utility crawls company list endpoints and prints simple matches.
