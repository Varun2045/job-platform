## 1. Pitch Materials

### Elevator Pitch (30 seconds)
> "Job Monitor is an open-source, autonomous career copilot that does more than track jobs—it proactively searches company career boards, normalizes and enriches the job postings using Playwright, and calculates real-time resume fit using cosine-similarity algorithms. Furthermore, it analyzes skill gaps to automatically output custom learning syllabi and study guides, notifying developers of new matches via email digests."

### Recruiter Pitch (Impact-Focused)
> "I built an enterprise-grade job search coordinator that automates the candidate funnel. The system monitors company career portals, ranks matches with an algorithmic match score, and tracks applications. By automating the scraping and matching pipeline, it cuts job-hunting overhead by 90% while providing real-time analytics to ensure candidates only spend time applying for high-probability, high-match roles."

## 2. Technical Interview Explanation

"During technical interviews, I explain the platform in three major stages:
1. **The Scraper Pipeline**: Resolves concurrency and rate-limiting using a priority-based stagger queue. I built a custom ATS detector that identifies Greenhouse, Lever, or Workday, falling back to a Cheerio or Playwright scraper.
2. **The Scoring & Resume Matching Engine**: Compares the crawled description against user profiles. It performs tokenization, TF-IDF vectorization, and computes cosine similarity scores adjusted by title heuristics.
3. **The Resiliency Layer**: Employs distributed Postgres advisory locks to prevent scraping conflicts, circuit breakers to suspend failing scrapers, and error-insulated email alert pipelines to guarantee uptime."

## 3. Demo Script (5-10 Minutes)

### Phase 1: Dashboard Overview (0:00 - 1:30)
- "Welcome to the Job Monitor Platform. We start at the central dashboard client showing active job postings and the candidate status pipeline."
- Show active analytics charts, matching threshold controls, and latest alerts.

### Phase 2: Active Monitoring Scrape (1:30 - 3:30)
- "Let's trigger a scraper orchestrator run using the CLI admin tool."
- Run `npm run monitor` in terminal. Show logs of the scraper queue processing, ATS detection, and job enrichment.
- "You can see the priority-based queue process tasks in parallel batches while respecting rate limits."

### Phase 3: Resume Matcher & Skill Gap (3:30 - 6:00)
- "Now look at the dashboard refresh. We have discovered a new Software Engineer posting. The system scored it at 92% based on our backend resume."
- Click on the job and show the missing skills highlight: "TypeScript, Docker, AWS".
- Show the auto-generated syllabus study guide containing targeted learning resources.

### Phase 4: Operations & Alerts (6:00 - 8:00)
- "Finally, we inspect the hourly digest email generated by Resend. It groups matches by company, sorted by fit score."
- Show Prometheus telemetry metrics file export.
